NEXT ACTION: UPLOAD THE WEBSITE CODE FILES
1. Extract the ZIP on your laptop.
2. Open the extracted folder. Select all the files inside it (HTML, CSS, JavaScript, and this README). Do not select the outer ZIP folder.
3. Open the repository root: https://github.com/amitadhikari-portfolio/amitadhikari
4. Choose Add file → Upload files.
5. Drag the selected files to the upload area. Replace the existing files with the same names and commit to main.
6. IMPORTANT: the 11 category files named certificates-additional.html, certificates-climate.html, certificates-conference.html, certificates-ecology.html, certificates-fao.html, certificates-fsc.html, certificates-ibm.html, certificates-issb.html, certificates-nptel.html, certificates-rsgis.html, and certificates-sdg.html must also be present at the repository root. Your last file list did not show these 11 files. This ZIP includes them.
